check2的本质是：已知加密后的 64 位密文(0xAD05217D, 0xF7C0C3E2)，求加密前的 64 位明文(x0, x1)（即part2的 8 字节）。需对sub_250F0执行逆运算（反向 32 轮），步骤如下：

（1）逆运算的核心前提

TEA 及其变种的运算在模2^32的无符号整数域中是可逆的（加法、异或、移位均为可逆操作），因此可通过反向推导每轮运算得到明文。

（2）逆运算的单轮逻辑（反向执行 32 轮）

正向运算的最后一轮v2值为delta*32 = 0x9E3779B9 * 32 = 0x1F66E6668（低 32 位为0xF66E6668）。逆运算时：

  • 从最终的v4=0xAD05217D、v3=0xF7C0C3E2和v2=0xF66E6668开始；
  • 逐轮反向计算：先反向更新v3，再反向更新v4，最后v2 -= delta（模2^32）；
  • 完成 32 轮逆运算后，得到的(v4, v3)即为part2的 64 位明文。

（3）明文转字符串
